# Roadmap

## 0 Foundation
- Independent repository and three-mode architecture
- Shared project contract
- Rust workspace and schema types
- Validation tests and fixtures

## 1 Manual editor MVP
- Import video, image and audio
- Multitrack timeline
- Trim, split, move and delete
- Preview and transforms
- Text and audio controls
- Save/open/autosave recovery
- Real FFmpeg MP4 export

## 2 Rendering platform
- Render plan
- Queue/status/progress/cancellation
- Headless CLI
- REST API and typed SDK
- Batch rendering and webhooks

## 3 AI Video Factory
- Prompt to brief/script/storyboard
- Asset generation/selection adapters
- Voice and captions
- Editable timeline generation
- Cost/rate/resource controls

## 4 Advanced creator features
- Keyframes, filters, transitions and masks
- Templates
- Plugins with permission boundaries

## 5 Platform
- Desktop/mobile clients
- Optional cloud projects and asset sync
- MCP after stable API contracts

A folder existing does not mean a feature is complete. Release gates require implementation, tests and reproducible builds.
